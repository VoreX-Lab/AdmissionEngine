# AdmissionEngine API 🎓

AdmissionEngine is a RESTful Web API built with C# and .NET Core designed to help prospective university students evaluate their chances of admission. It computes aggregate scores based on UTME and O'Level input metrics, cross-references target departmental requirements, and dynamically generates alternative course recommendations if requirements fall short.

## 🚀 Key Features

- **Eligibility Calculation:** Evaluates aggregate scores against institutional cut-off points.
- **Smart Recommendations:** Returns suitable alternative fields of study based on subject combinations and current score thresholds.
- **RESTful Endpoints:** Provides structured JSON response models for easy integration with frontend clients (React/Vue/Mobile).

## 🛠️ Tech Stack

- **Language:** C#
- **Framework:** ASP.NET Core Web API
- **Architecture:** Controller/Service Pattern
